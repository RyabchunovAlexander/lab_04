# Лабораторная работа №4 — Алгоритмический мини-пакет

Лабораторная работа №4 по предмету «Программирование на Python». Устанавливаемый пакет `algopack` с алгоритмами сортировки, вычислением НОД, очередью с приоритетом, генераторами данных и инструментами измерения производительности.

## Что делает программа

- **Алгоритм Евклида** — вычисляет НОД двух целых чисел итеративным и рекурсивным способами.
- **Selection Sort** — сортировка выбором с квадратичной сложностью O(n²).
- **Heap Sort** — пирамидальная сортировка на основе двоичной кучи со сложностью O(n log n).
- **Priority Queue** — очередь с приоритетом, поддерживающая добавление, извлечение, просмотр элементов, `len` и `bool`.
- **Генераторы данных** — создают случайные, отсортированные, обратные, почти отсортированные массивы и массивы с большим количеством повторений.
- **Benchmark** — сравнивает производительность сортировок на разных типах и размерах входных данных, сохраняет результаты в CSV.

## Пример использования

```python
from algopack.gcd import gcd_iterative, gcd_recursive
from algopack.selection_sort import selection_sort
from algopack.heap_sort import heap_sort
from algopack.priority_queue import PriorityQueue
from algopack.generators import generate_random

# Генерация массива
numbers = generate_random(10, seed=42)

# Сортировки возвращают новый список
print(selection_sort(numbers))
print(heap_sort(numbers))

# Вычисление НОД
print(gcd_iterative(48, 18))
print(gcd_recursive(48, 18))

# Очередь с приоритетом
queue = PriorityQueue()
queue.push("Обычная задача", 1)
queue.push("Срочная задача", 10)

print(queue.peek())
print(queue.pop())
```

## Анализ сложности и ограничения

| Алгоритм / операция | Время | Доп. память |
|---|---|---|
| НОД (итеративный) | O(log n) | O(1) |
| НОД (рекурсивный) | O(log n) | O(log n) |
| Selection Sort | O(n²) | O(n) |
| Heap Sort | O(n log n) | O(n) |
| Priority Queue: `push` | O(n) | O(1)* |
| Priority Queue: `pop`, `peek`, `len`, `bool` | O(1) | O(1) |

Для НОД оценка приведена в стандартной модели арифметических операций. Дополнительная память сортировок учитывает копирование входного списка.

*Для `push` не учитывается возможное перераспределение памяти внутреннего списка.*

**Особенности реализации:**

- Сортировки возвращают новый список и не изменяют исходный. Внутри алгоритмов не используются `sorted()` и `list.sort()`.
- Поддерживаются пустые списки, отрицательные числа и дубликаты.
- Очередь реализована на основе упорядоченного списка. Первым извлекается элемент с максимальным приоритетом, при равных приоритетах сохраняется порядок добавления.
- Собственные исключения: `ArgTypeError`, `ArgValueError`, `GCDError`, `EmptyQueueError`.
- Глубина рекурсии Python ограничена (`sys.getrecursionlimit()`). При превышении лимита возникает `RecursionError`. Итеративный алгоритм Евклида этого ограничения не имеет.

## Benchmark

Для каждого типа и размера массива выполняется **5 повторов**. Генерация данных не включается в измеряемое время, для каждого запуска используется независимая копия входного массива.

**Размеры входных данных:**

- **Selection Sort:** 100, 1 000, 10 000.
- **Heap Sort:** 100, 1 000, 10 000, 100 000, 1 000 000, 10 000 000.

Проверяются все пять типов массивов. Время измеряется через `time.perf_counter()`.

Результаты сохраняются в файлы:

- `benchmark.csv` — среднее, минимальное, максимальное время и коэффициенты роста.
- `benchmark_runs.csv` — результаты каждого отдельного измерения.

### Сопоставление с ожидаемой сложностью

Для каждого размера и типа массива выполнено 5 измерений,
всего — 225 запусков.

На случайном массиве из 10 000 элементов:
- Selection Sort: 721,190 мс.
- Heap Sort: 10,217 мс.

Таким образом, Heap Sort работает примерно в 70,6 раза быстрее.

При увеличении размера массива в 10 раз время Selection Sort
возрастает примерно в 94–101 раз, что согласуется с O(n²).

Для Heap Sort рост времени на больших массивах составляет
примерно 13–14,5 раза, что согласуется с O(n log n).

Экспериментальные результаты подтверждают ожидаемую
асимптотическую сложность обоих алгоритмов.

## Тестирование

Автоматические тесты `pytest` проверяют:

- Корректность обоих алгоритмов Евклида.
- Пустые массивы, один элемент, отсортированные и обратные данные.
- Отрицательные числа, дубликаты и сохранение исходного списка.
- Операции очереди с приоритетом и исключения для пустой очереди.
- Инвариант структуры данных.
- Работу всех генераторов и воспроизводимость через `seed`.
- Обработку некорректных аргументов.
